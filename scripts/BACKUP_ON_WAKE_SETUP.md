# Настройка бэкапа при пробуждении ноутбука

## 🎯 Как это работает

**Простая логика:**
1. Вы открываете ноутбук (пробуждаете его из сна)
2. Система автоматически проверяет: есть ли бэкап за сегодняшний день?
3. **Если бэкапа НЕТ** → создается новый бэкап ✅
4. **Если бэкап УЖЕ ЕСТЬ** → пропускается (один раз в сутки)

**Примеры:**
- Утро (8:00): открываете ноутбук → бэкап создается
- День (14:00): открываете ноутбук снова → бэкап НЕ создается (уже был утром)
- Вечер (20:00): открываете ноутбук → бэкап НЕ создается (уже был утром)
- Следующий день (8:00): открываете ноутбук → новый бэкап создается ✅

## Установка (один шаг)

```bash
cd /Users/evgenijstolarov/Documents/JavaProjects/ufc_stats
./scripts/setup-backup-on-wake.sh
```

Скрипт автоматически:
- Создаст необходимые директории
- Скопирует конфигурацию в `~/Library/LaunchAgents/`
- Запустит задачу

## Управление задачей

### Просмотр статуса
```bash
launchctl list | grep ufcstats
```

### Остановить автоматический бэкап
```bash
launchctl unload ~/Library/LaunchAgents/com.ufcstats.backup.wakeup.plist
```

### Запустить автоматический бэкап
```bash
launchctl load ~/Library/LaunchAgents/com.ufcstats.backup.wakeup.plist
```

### Перезапустить задачу
```bash
launchctl unload ~/Library/LaunchAgents/com.ufcstats.backup.wakeup.plist
launchctl load ~/Library/LaunchAgents/com.ufcstats.backup.wakeup.plist
```

### Полностью удалить задачу
```bash
launchctl unload ~/Library/LaunchAgents/com.ufcstats.backup.wakeup.plist
rm ~/Library/LaunchAgents/com.ufcstats.backup.wakeup.plist
```

## Просмотр логов

Логи автоматического бэкапа сохраняются в:
- `backups/wake-backup.log` - основной лог бэкапа при пробуждении
- `backups/launchd-wakeup.log` - лог запуска от launchd
- `backups/backup.log` - основной лог бэкапов (от скрипта backup-db.sh)

```bash
# Посмотреть последние записи
tail -f backups/wake-backup.log

# Посмотреть основные логи бэкапа
tail -f backups/backup.log
```

## Ручной бэкап

Даже с автоматическим бэкапом вы можете создавать бэкапы вручную в любое время:

```bash
./scripts/backup-db.sh backup
```

Ручной бэкап не зависит от автоматического - можно создать сколько угодно.

## Проверка работы

После установки можно проверить, что задача работает:

1. **Проверьте статус:**
   ```bash
   launchctl list | grep ufcstats
   ```
   Должна быть видна задача `com.ufcstats.backup.wakeup`

2. **Посмотрите логи:**
   ```bash
   tail -f backups/wake-backup.log
   ```

3. **Симуляция пробуждения:**
   - Положите ноутбук в сон
   - Разбудите его
   - Проверьте логи - должен быть запуск проверки

## Часто задаваемые вопросы

**Q: Бэкап создается каждый раз при пробуждении?**  
A: Нет, только один раз в сутки. При повторных пробуждениях проверяется наличие сегодняшнего бэкапа.

**Q: Что если я хочу сделать бэкап дважды в день?**  
A: Используйте ручной бэкап: `./scripts/backup-db.sh backup`

**Q: Работает ли это при полном выключении компьютера?**  
A: Да, при следующем включении система проверит наличие сегодняшнего бэкапа и создаст его, если нужно.

**Q: Как узнать, был ли создан бэкап сегодня?**  
A: Проверьте логи: `tail -f backups/wake-backup.log` или посмотрите файлы: `ls -la backups/ufc_stats_backup_$(date +%Y%m%d)_*.zip`
