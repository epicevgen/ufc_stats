# Настройка автоматического бэкапа на macOS

## 🎯 Как это работает

**Важно понять:** Обычные задачи по расписанию (`StartCalendarInterval`) **не выполняются автоматически при пробуждении**, если компьютер спал во время запланированного запуска.

**Наше решение:** Комбинированный подход:
1. **Основная задача** (2:00 ночи) - выполняется, если компьютер активен
2. **Задача при пробуждении** - проверяет при каждом пробуждении, нужен ли бэкап
   - Если последний бэкап был >1 часа назад → создает новый
   - Если бэкап недавний → пропускает (защита от дубликатов)

**Практический пример:**
- Ложитесь спать в 23:00 (компьютер спит)
- В 2:00 задача пропускается (компьютер спит)
- Просыпаетесь в 8:00 → задача при пробуждении создает бэкап ✅

## Проблема с cron на ноутбуках

На ноутбуках macOS обычный `cron` не работает надежно, потому что:
- Задачи не выполняются, если компьютер в режиме сна
- Задачи могут пропуститься, если ноутбук был выключен

## Решение: launchd

Для macOS используется **launchd** - системный демон, который:
- Может запускать задачи при различных событиях (подключение к сети, пробуждение)
- Более надежен, чем cron
- Интегрирован в систему macOS

## Варианты настройки

### Вариант 1: Комбинированный подход (рекомендуется)

**Как работает:**
- **Основная задача**: Настроена на 2:00 ночи, выполняется если компьютер активен
- **Задача при пробуждении**: Дополнительная страховка - проверяет, нужно ли сделать бэкап при пробуждении компьютера
- Если бэкап уже был сделан менее часа назад - пропускается (не создается дубликат)
- Если компьютер спал в 2:00 - бэкап будет сделан при следующем пробуждении (если прошло больше часа)

**Установка:**
```bash
cd /Users/evgenijstolarov/Documents/JavaProjects/ufc_stats
chmod +x scripts/setup-backup-schedule.sh
./scripts/setup-backup-schedule.sh
```

**Как это работает на практике:**
- Компьютер активен в 2:00 → бэкап создается в 2:00
- Компьютер спит в 2:00 → бэкап создается при следующем пробуждении (если прошло >1 часа)
- Пример: Ложитесь спать в 23:00, просыпаетесь в 8:00 → бэкап создастся при пробуждении

### Вариант 2: Бэкап при пробуждении компьютера

Если вы хотите, чтобы бэкап создавался каждый раз, когда ноутбук просыпается (но не чаще раза в час):

1. Используйте скрипт `backup-on-wake.sh`
2. Настройте его как LaunchAgent, который срабатывает при пробуждении

**Установка (вариант 2):**
```bash
cd /Users/evgenijstolarov/Documents/JavaProjects/ufc_stats

# Делаем скрипт исполняемым
chmod +x scripts/backup-on-wake.sh

# Копируем plist в LaunchAgents
cp scripts/com.ufcstats.backup.wakeup.plist ~/Library/LaunchAgents/

# Загружаем задачу
launchctl load ~/Library/LaunchAgents/com.ufcstats.backup.wakeup.plist
```

## Управление задачей

### Просмотр статуса
```bash
launchctl list | grep ufcstats
```

### Остановить автоматический бэкап
```bash
launchctl unload ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
```

### Запустить автоматический бэкап
```bash
launchctl load ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
```

### Перезапустить задачу
```bash
launchctl unload ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
launchctl load ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
```

### Полностью удалить задачу
```bash
launchctl unload ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
rm ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
```

## Просмотр логов

Логи автоматического бэкапа сохраняются в:
- `backups/launchd-schedule.log` - стандартный вывод
- `backup.log` - основной лог бэкапов
- `backups/wake-backup.log` - лог для варианта с пробуждением

```bash
# Посмотреть последние записи
tail -f backups/launchd-schedule.log

# Посмотреть основные логи бэкапа
tail -f backups/backup.log
```

## Ручной бэкап

Даже с автоматическим бэкапом вы можете создавать бэкапы вручную:

```bash
./scripts/backup-db.sh backup
```

## Рекомендации

1. **Для ноутбука**: Используйте вариант 1 (ежедневный бэкап). Если ноутбук часто в спящем режиме, делайте ручные бэкапы перед выключением.

2. **Для десктопа**: Вариант 1 работает отлично, так как компьютер обычно активен в ночное время.

3. **Проверяйте логи**: Периодически проверяйте логи, чтобы убедиться, что бэкапы создаются.

4. **Дополнительная защита**: Периодически копируйте бэкапы в облачное хранилище (iCloud, Google Drive и т.д.)

## Изменение времени бэкапа

Если хотите изменить время (например, на 3:00 ночи):

1. Отредактируйте файл:
```bash
nano ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
```

2. Измените значение `Hour`:
```xml
<key>Hour</key>
<integer>3</integer>
```

3. Перезагрузите задачу:
```bash
launchctl unload ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
launchctl load ~/Library/LaunchAgents/com.ufcstats.backup.schedule.plist
```

## Альтернатива: Комбинированный подход

Можно использовать оба варианта:
- Ежедневный бэкап в 2:00 (если компьютер активен)
- Бэкап при пробуждении (как дополнительная страховка)

Оба скрипта умные - они не будут создавать бэкапы слишком часто.
