# UFC Stats - Обзор проекта

## Описание проекта

**UFC Stats** - это веб-приложение для отслеживания и анализа статистики боев в игре UFC 5. Приложение позволяет пользователям записывать результаты своих боев, анализировать статистику и отслеживать прогресс.

## Основные возможности

### 🥊 Управление боями
- **Добавление боев**: Запись детальной информации о каждом бое
- **Просмотр списка**: Отображение всех боев с фильтрацией и поиском
- **Детальная информация**: Полная статистика по каждому бою
- **Редактирование**: Изменение данных о боях

### 📊 Аналитика и статистика
- **Основные показатели**: Общая статистика побед/поражений
- **Детальная аналитика**: Статистика по режимам, весовым категориям
- **Фильтрация**: Анализ по сезонам и режимам боев
- **Визуализация**: Графики и диаграммы для наглядности

### 🎯 Дополнительные функции
- **Тестовые данные**: Генерация тестовых боев для демонстрации
- **Резервное копирование**: Автоматическое сохранение данных
- **Адаптивный дизайн**: Работа на всех устройствах

## Архитектура приложения

### Структура пакетов
```
com.ufcstats/
├── config/          # Конфигурация приложения
├── controller/      # REST и веб контроллеры
├── dto/            # Data Transfer Objects
├── model/          # Модели данных и enums
├── repository/     # Репозитории для работы с БД
├── service/        # Бизнес-логика
└── util/           # Утилиты и вспомогательные классы
```

### Основные компоненты

#### Модели данных
- **Fight** - Основная модель боя
- **FightResult** - Результат боя (WIN, LOSS, DRAW)
- **FightMode** - Режим боя (MMA, STANCE)
- **FightMethod** - Способ завершения боя
- **WeightClass** - Весовая категория

#### Сервисы
- **FightService** - Основная бизнес-логика
- **AdvancedStatisticsService** - Расширенная аналитика
- **FighterStatisticsService** - Статистика бойца
- **StrikeMovementService** - Анализ ударов
- **AchievementStatisticsService** - Достижения

#### Контроллеры
- **WebController** - Основные веб-страницы
- **FightController** - REST API для боев
- **TestDataController** - Генерация тестовых данных

## База данных

### Схема
- **Fight** - Таблица боев с основной информацией
- **FightRound** - Раунды боев (удалено в текущей версии)
- **JudgeScore** - Судейские оценки (удалено в текущей версии)

### Миграции
- **V1__Initial_schema.sql** - Начальная схема
- **V2__Create_fight_tables.sql** - Создание таблиц боев
