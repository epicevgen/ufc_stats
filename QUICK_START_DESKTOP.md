# 🚀 Быстрый старт: Создание нативного приложения

## 🎯 Цель
Создать нативное приложение UFC Stats, которое запускается по иконке на рабочем столе.

## ⚡ Быстрый способ

### **1. Создание установщика**
```bash
# Запустите скрипт быстрого создания
./scripts/quick-installer.sh
```

### **2. Установка приложения**
```bash
# Откройте созданный .dmg файл
open dist-electron/UFC\ Stats-1.0.0.dmg

# Перетащите приложение в Applications
# Запустите из Applications или Launchpad
```

## 🎨 Создание иконки

### **Автоматическое создание**
Иконка уже создана в `assets/icon.svg` - это SVG файл с дизайном UFC Stats.

### **Ручное создание**
1. **Создайте PNG файл 512x512 пикселей**
2. **Сохраните как `assets/icon.png`**
3. **Используйте онлайн-генераторы:**
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/

## 📱 Результат

После установки у вас будет:
- ✅ **Приложение в Applications** (macOS)
- ✅ **Иконка в Launchpad** (macOS)
- ✅ **Возможность запуска по иконке**
- ✅ **Нативное меню и интерфейс**

## 🔧 Команды

```bash
# Создание установщика
./scripts/quick-installer.sh

# Запуск в режиме разработки
npm run electron

# Сборка для всех платформ
npm run build
```

## 🎉 Готово!

Теперь у вас есть полноценное нативное приложение UFC Stats! 🚀
